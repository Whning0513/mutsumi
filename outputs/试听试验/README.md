# 临时试听区

这里用于新一轮参数扫测、短期 A/B 对照和复刻生成。确认有长期用途的版本请记入文档并移入 `outputs/基线/`；一轮实验结束后，把不再常用的片段放入 `outputs/archieve/<批次>/试听试验/`。

已命名的四条若叶睦基线集中在 `outputs/基线/`。用户选中的激动基线 GSV 原声也曾保留在旧试听路径，与基线目录中的规范文件逐字节相同；制作时优先使用 `outputs/基线/激动若叶睦基线_GSV原声_学妹饭卡.wav`。旧试听和参数比较见本地归档索引 `outputs/archieve/20261116_cleanup/README.md`。音频文件不提交到 Git。
