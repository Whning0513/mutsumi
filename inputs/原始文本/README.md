# 原始文本

放收到或撰写后尚未整理的原文，保留原始内容。清理、改写或切分后的朗读稿另存到 `../台本/`，不要覆盖原文。

## 连续文案池

在本地 `文案池.txt` 中持续追加文案，每条文案之间留一个空行。空行就是严格的分段边界；段内可以换行，取用时不会从段内按句子或语义截取：

```text
这里粘贴一整段原始文案。

下一段原始文案。
```

工具按文案顺序分配 `copy-001`、`copy-002` 等 ID。只在文件末尾追加新段，保持已有 ID 稳定。状态存入本地旁车文件 `文案池.status.json`，源文案内容不被改写。先列出状态，再按 ID 取一整块：

```sh
python3 scripts/take_copy.py list
python3 scripts/take_copy.py take copy-001 --max-chars 220
```

取用命令只接受完整段落 ID，不按句号或语义搜索/截取。它调用 `scripts/prepare_tts_text.py` 清理选中内容；成功后才把状态记为 `已取`。默认台本写入 `inputs/台本/copy-001.txt`，固定长度分块写入 `outputs/文案切块/copy-001/`。

超长块在清理标点和 emoji 后，按 Unicode 字符数每 220 字硬切；不寻找句号、分句或语义边界，可能切在词中或标点处。需要别的长度时传 `--max-chars`。原文池保持原样，只修改已取状态。
