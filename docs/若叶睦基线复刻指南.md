# 若叶睦命名基线复刻指南

记录日期：2026-11-16

本页把已经命名的若叶睦基线逐一写成可复跑的配方：固定输入素材、模型权重、关键参数、CPU 命令和试听文件。复跑从**现成输入音频或已保存的微调权重**开始；不重新训练 GSV 微调权重。微调数据来源、切分和训练记录见[环境与模型记录](环境与模型记录.md#视频中的急促哭腔语气5-秒参考与短数据微调)。

命令在远程主机 `a100-whn` 上执行，但显式隐藏 CUDA 并使用 CPU。GSV 采样可能变化，复跑旨在保持素材与设置相同，不保证 WAV 逐样本一致。命令统一把新文件写进 `outputs/试听试验/复刻/`，不覆盖已选的基线样本。

| 已命名基线 | 复刻配方 | 用户选定的试听文件 |
| --- | --- | --- |
| 无口若叶睦基线 | Qwen 汉堡独白源音频 → 低索引 RVC | [低索引版](../outputs/基线/无口若叶睦基线_RVC_汉堡独白_低索引.wav) |
| 日常若叶睦基线 | Qwen 太阳宣言源音频 → RVC，`index=0.30`、`pitch=-1` | [太阳宣言参数版](../outputs/基线/日常若叶睦基线_RVC_太阳宣言_index030_pitch-1.wav) |
| 抽泣若叶睦基线 v1 | 28 秒视频微调 GSV + 5 秒哭腔参考 + 睡不醒朗读稿 | [睡不醒 GSV](../outputs/基线/抽泣若叶睦基线_v1_GSV_睡不醒.wav) |

## 一、RVC 共用 CPU 环境

以下环境在远程 `a100-whn` 的 shell 中设置一次，供“无口”和“日常”两个 RVC 配方复用：

```bash
cd /data3/whn/Project-voca/frameworks/RVC
export PYTHONPATH=/data3/whn/Project-voca/frameworks/RVC:/data3/whn/Project-voca/.venv-qwen/lib/python3.10/site-packages:/data3/whn/Project-voca/.venv-rvc-cpu/lib/python3.10/site-packages
export rmvpe_root=/data3/whn/Project-voca/assets/rvc
export CUDA_VISIBLE_DEVICES=
export OMP_NUM_THREADS=32 MKL_NUM_THREADS=32 OPENBLAS_NUM_THREADS=1 RVC_AUDIO_FORCE_CPU=1
mkdir -p /data3/whn/Project-voca/outputs/试听试验/复刻
```

共用模型和索引：

```text
/data3/whn/Project-voca/models/rvc/mutsumi-rvc/mutsumi.pth
/data3/whn/Project-voca/models/rvc/mutsumi-rvc/added_IVF345_Flat_nprobe_1_mutsumi_v2.index
```

如果远程缺少某个固定输入，可从本地归档拷回。只在目标文件确实缺失时执行，避免替换已有输入：

```bash
# 无口基线的 Qwen 汉堡源音频
scp 'outputs/archieve/202611052130/若叶睦_汉堡独白.wav' \
  'a100-whn:/data3/whn/Project-voca/outputs/若叶睦_汉堡独白.wav'

# 日常基线的 Qwen 太阳宣言源音频
scp 'outputs/archieve/202611052130/试听试验/若叶睦_Qwen_太阳宣言_原声.wav' \
  'a100-whn:/data3/whn/Project-voca/outputs/试听试验/若叶睦_Qwen_太阳宣言_原声.wav'
```

## 二、无口若叶睦基线

固定输入是已保存的 Qwen 汉堡独白源音频：远程 `/data3/whn/Project-voca/outputs/若叶睦_汉堡独白.wav`；本地归档副本为[若叶睦_汉堡独白.wav](../outputs/archieve/202611052130/若叶睦_汉堡独白.wav)。命名基线参数：`index=0.15`、`pitch=0`、`rms-mix-rate=0.45`、`protect=0.45`、RMVPE。它是平静、少语风格参照，不是纯文本直出的 TTS。

选定样本为 24.86 秒、40 kHz、单声道，RMS -19.74 dBFS、峰值 -6.19 dBFS。

在上述 RVC 环境中执行：

```bash
/data3/whn/Project-voca/.venv-rvc-cpu/bin/python infer/cli.py \
  --model /data3/whn/Project-voca/models/rvc/mutsumi-rvc/mutsumi.pth \
  --input /data3/whn/Project-voca/outputs/若叶睦_汉堡独白.wav \
  --output /data3/whn/Project-voca/outputs/试听试验/复刻/若叶睦_RVC_汉堡独白_低索引.wav \
  --index /data3/whn/Project-voca/models/rvc/mutsumi-rvc/added_IVF345_Flat_nprobe_1_mutsumi_v2.index \
  --index-rate 0.15 --rms-mix-rate 0.45 --protect 0.45 \
  --pitch 0 --f0-method rmvpe
```

如果 Qwen 源音频不在远程 `outputs/`，可用 `scripts/generate_qwen_voice_cpu.py` 读取本地私有朗读稿并指定 `--speaker mujica_mutsumi`、`--output` 重建。该源音频只作为 RVC 输入；历史朗读稿不在公开仓库中。Qwen 权重位置和脚本记录见[环境与模型记录](环境与模型记录.md#qwen3-tts-直接合成配置直出未选作最终音色)。

## 三、日常若叶睦基线

固定输入为远程 `/data3/whn/Project-voca/outputs/试听试验/若叶睦_Qwen_太阳宣言_原声.wav`，本地归档副本为[若叶睦_Qwen_太阳宣言_原声.wav](../outputs/archieve/202611052130/试听试验/若叶睦_Qwen_太阳宣言_原声.wav)。命名基线参数为 `index=0.30`、`pitch=-1`、`rms-mix-rate=0.45`、`protect=0.50`、RMVPE。`index=0.15 / pitch=0` 也是同一输入上的好评对照，但不替代这条命名基线。

太阳宣言的六条历史 RVC 对照输出均约 16.86 秒，RMS 约 -19.2 至 -19.4 dBFS；完整测量记录见[环境与模型记录](环境与模型记录.md#protect-上限音高与索引率新对照)。

在 RVC 共用环境中执行：

```bash
/data3/whn/Project-voca/.venv-rvc-cpu/bin/python infer/cli.py \
  --model /data3/whn/Project-voca/models/rvc/mutsumi-rvc/mutsumi.pth \
  --input /data3/whn/Project-voca/outputs/试听试验/若叶睦_Qwen_太阳宣言_原声.wav \
  --output /data3/whn/Project-voca/outputs/试听试验/复刻/若叶睦_RVC_太阳宣言_protect050_index030_pitch-1.wav \
  --index /data3/whn/Project-voca/models/rvc/mutsumi-rvc/added_IVF345_Flat_nprobe_1_mutsumi_v2.index \
  --index-rate 0.30 --rms-mix-rate 0.45 --protect 0.50 \
  --pitch -1 --f0-method rmvpe
```

Qwen 源音频由 `scripts/run_mutsumi_sun_sweep_cpu.py` 使用归档的 `mujica_mutsumi` 权重和本地私有测试稿生成。当前远程和本地归档均有这条源音频，复刻时优先复用固定 WAV。若只要重建日常配方对应的扫描点，可选择单个变体并复用源文件，例如 `--skip-source --variants i030_p-1`；脚本默认拒绝覆盖已有文件，只有显式 `--overwrite` 才替换。

## 四、抽泣若叶睦基线 v1

基线样本是[睡不醒 GSV 微调版](../outputs/基线/抽泣若叶睦基线_v1_GSV_睡不醒.wav)，输入文案为[`睡不醒_测试文本.txt`](../scripts/睡不醒_测试文本.txt)。若该文本尚未同步到远程，先在本地执行：

```bash
scp 'scripts/睡不醒_测试文本.txt' \
  'a100-whn:/data3/whn/Project-voca/scripts/睡不醒_测试文本.txt'
```

若远程缺少哭腔参考音频，也在本地项目根目录的终端从素材目录补上：

```bash
scp 'training_data/video_style_28sec/BV1XJpB6pEvu_5sec_cry_reference.wav' \
  'a100-whn:/data3/whn/Project-voca/training_data/video_style_28sec/BV1XJpB6pEvu_5sec_cry_reference.wav'
```

在远程项目根目录设置 GSV 环境：

```bash
cd /data3/whn/Project-voca
export PYTHONPATH=/data3/whn/Project-voca/frameworks/GPT-SoVITS:/data3/whn/Project-voca/frameworks/GPT-SoVITS/GPT_SoVITS:/data3/whn/Project-voca/.venv-gpt-sovits-cpu/lib/python3.10/site-packages:/data3/whn/Project-voca/.venv-qwen/lib/python3.10/site-packages
export CUDA_VISIBLE_DEVICES='' HF_HUB_OFFLINE=1 TRANSFORMERS_OFFLINE=1
export OMP_NUM_THREADS=32 MKL_NUM_THREADS=32 OPENBLAS_NUM_THREADS=1
```

然后运行：

```bash
/data3/whn/Project-voca/.venv-gpt-sovits-cpu/bin/python scripts/generate_gsv_zeroshot_cpu.py \
  --reference /data3/whn/Project-voca/training_data/video_style_28sec/BV1XJpB6pEvu_5sec_cry_reference.wav \
  --prompt-text-file /data3/whn/Project-voca/training_data/video_style_28sec/5sec_cry_reference_prompt.txt \
  --text-file /data3/whn/Project-voca/scripts/睡不醒_测试文本.txt \
  --sovits-weight /data3/whn/Project-voca/models/gpt-sovits/finetuned/video_style_28sec/SoVITS/MutsumiVideo28sec_e8_s768.pth \
  --gpt-weight /data3/whn/Project-voca/models/gpt-sovits/finetuned/video_style_28sec/GPT/MutsumiVideo28sec-e15.ckpt \
  --top-k 15 --top-p 0.6 --temperature 0.6 --speed 1.0 --target-rms-dbfs -27 \
  --output /data3/whn/Project-voca/outputs/试听试验/复刻/睡不醒_GSV_28秒微调_5秒哭腔参考.wav
```

该基线是 GSV 直出。参考音频和短微调素材都带哭腔，所以声音会持续偏抽泣/黏糊；具体原因与听感记录见[实践指南](模型与实践指南.md#抽泣若叶睦基线-v1)。

本地选定样本为 22.22 秒、32 kHz、单声道；合成脚本把 RMS 目标设为 -27 dBFS。

## 五、激动若叶睦基线

用户指定[学妹饭卡 GSV 原声](../outputs/基线/激动若叶睦基线_GSV原声_学妹饭卡.wav)为激动基线：反馈是音色完全正确、音高正常、整体质量很好，只有轻微不干净。**基线是 GSV 原声，不经过 RVC，也不使用响度匹配版。** 输入台词为[若叶睦_学妹饭卡小剧场_测试文本.txt](../scripts/若叶睦_学妹饭卡小剧场_测试文本.txt)。若远程副本缺失，在本地执行：

```bash
scp 'scripts/若叶睦_学妹饭卡小剧场_测试文本.txt' \
  'a100-whn:/data3/whn/Project-voca/scripts/若叶睦_学妹饭卡小剧场_测试文本.txt'
```

哭腔参考和微调权重路径同上一节；两段 GSV 基线仅更换目标朗读稿，仍用相同参考片段、参考文字和采样参数。

复用上一节的 GSV CPU 环境，然后运行：

```bash
/data3/whn/Project-voca/.venv-gpt-sovits-cpu/bin/python scripts/generate_gsv_zeroshot_cpu.py \
  --reference /data3/whn/Project-voca/training_data/video_style_28sec/BV1XJpB6pEvu_5sec_cry_reference.wav \
  --prompt-text-file /data3/whn/Project-voca/training_data/video_style_28sec/5sec_cry_reference_prompt.txt \
  --text-file /data3/whn/Project-voca/scripts/若叶睦_学妹饭卡小剧场_测试文本.txt \
  --sovits-weight /data3/whn/Project-voca/models/gpt-sovits/finetuned/video_style_28sec/SoVITS/MutsumiVideo28sec_e8_s768.pth \
  --gpt-weight /data3/whn/Project-voca/models/gpt-sovits/finetuned/video_style_28sec/GPT/MutsumiVideo28sec-e15.ckpt \
  --top-k 15 --top-p 0.6 --temperature 0.6 --speed 1.0 --target-rms-dbfs -27 \
  --output /data3/whn/Project-voca/outputs/试听试验/复刻/若叶睦_学妹饭卡_GSV_28秒微调_5秒哭腔参考.wav
```

样本为 22.04 秒、32 kHz、单声道、RMS -27 dBFS。相同 GSV 输出的 RVC 单次转换版和响度匹配版只作为 A/B 对照，不是激动基线。

## 取回复刻音频

在本地项目根目录使用对应文件名取回，例如：

```bash
scp 'a100-whn:/data3/whn/Project-voca/outputs/试听试验/复刻/若叶睦_学妹饭卡_GSV_28秒微调_5秒哭腔参考.wav' \
  'outputs/试听试验/若叶睦_学妹饭卡_GSV_28秒微调_5秒哭腔参考_复刻.wav'
```

将命令中的两个文件名换成“睡不醒”或对应的 RVC 输出名，即可取回其他复刻结果。原先用户选定的基线 WAV 都已保存在本地项目链接所指位置；复刻文件带 `_复刻` 后缀，便于同条件试听而不混淆原版。

F0 差分估算和环境/权重位置见[环境与模型记录](环境与模型记录.md)；模型与素材来源见[模型与实践指南](模型与实践指南.md)。
