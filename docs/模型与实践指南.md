# 模型与实践指南

记录日期：2026-11-16

这份指南汇总当前采用的模型、音色转换参数、音源准备方式和已验证的操作经验。模型与推理框架在远程主机 `a100-whn`；本地工作区保存素材、脚本、试听结果和文档。

四个命名基线（无口、日常、抽泣 v1、激动）的输入、权重、参数和完整复刻命令集中在[若叶睦基线复刻指南](若叶睦基线复刻指南.md)。

## 当前模型与参数

### 主用：若叶睦 RVC v2 音色转换

RVC 把已有的人声录音或其他 TTS 的音频转换为目标音色；它不直接从文本生成语音。当前用的是若叶睦 RVC v2 模型，模型卡偏向歌声转换，普通话朗读属于试听验证过的用法。

| 项目 | 当前配置 |
| --- | --- |
| 模型 | `/data3/whn/Project-voca/models/rvc/mutsumi-rvc/mutsumi.pth` |
| 配套索引 | `/data3/whn/Project-voca/models/rvc/mutsumi-rvc/added_IVF345_Flat_nprobe_1_mutsumi_v2.index` |
| HuBERT / RMVPE 等资源 | `/data3/whn/Project-voca/assets/rvc` |
| Python 环境 | `/data3/whn/Project-voca/.venv-rvc-cpu/bin/python`；通过 `PYTHONPATH` 复用 `.venv-qwen` 中的 Torch 等依赖 |
| 推理设备 | CPU；设置 `CUDA_VISIBLE_DEVICES=` 和 `RVC_AUDIO_FORCE_CPU=1` |
| 索引混合率 | `index-rate=0.30` |
| 响度混合率 | `rms-mix-rate=0.45` |
| 保护参数 | `protect=0.50` |
| 基频提取 | `f0-method=rmvpe` |
| 输出 | 40 kHz、单声道 WAV；当前试听约 39.16 秒 |

音高要随输入声线调整，不能把同一个值套到所有素材：

| 音源 / 用途 | Pitch | 试听结论 |
| --- | ---: | --- |
| 低男音、多腔调的《离骚》朗读 | 重点比较 `+14` 到 `+18`；另做了 `+15`、`+17`、`+18`、`+19` | 用户认为 `+16` 已很接近，`+14` 到 `+18` 都值得比较；`+19` 用作更高一档的参照 |
| 太阳宣言历史参数对照 | `-1` | 当时在太阳宣言文本上选定；来源和音色条件不同，不是《离骚》的默认值 |
| 汉堡独白“无口”风格参考 | `0` | 曾用 `index-rate=0.15`；用户反馈风格和音质可用，适合作为平静语气参考 |

《离骚》输入音频是[离骚-whn.m4a](../视频音频下载/离骚-whn.m4a)。现有对照音频见 [P14](../outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P14_i030.wav)、[P15](../outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P15_i030.wav)、[P16](../outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P16_i030.wav)、[P17](../outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P17_i030.wav)、[P18](../outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P18_i030.wav) 和 [P19](../outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P19_i030.wav)。文件名中的 `P16_i030` 表示 pitch `+16`、index rate `0.30`。

### 文本到若叶睦：Qwen3-TTS → RVC

太阳宣言这组是文字先由 Qwen3-TTS 的 `mujica_mutsumi` speaker 生成普通话，再由若叶睦 RVC v2 转换音色。用户明确命名的**日常若叶睦基线**是 [index 0.30 / pitch -1 版本](../outputs/基线/日常若叶睦基线_RVC_太阳宣言_index030_pitch-1.wav)，参数为 `index-rate=0.30`、`pitch=-1`、`rms-mix-rate=0.45`、`protect=0.50`、RMVPE。同一文本的 [index 0.15 / pitch 0 版本](../outputs/archieve/202611052130/试听试验/若叶睦_RVC_太阳宣言_protect050_index015_pitch0.wav)也得到过好评，是独立对照，不替代已命名基线。

因此，直接 Qwen 合成和 Qwen→RVC 是两种不同结果：前者不是当前认可的最终音色；后者是目前已有正面试听反馈的文字到若叶睦候选流程。Qwen 权重仍在远程归档目录，由 [`run_mutsumi_sun_sweep_cpu.py`](../scripts/run_mutsumi_sun_sweep_cpu.py) 读取并生成原声及 RVC 参数对照。

### 历史实验模型

- **Qwen3-TTS 睦角色权重**：`mujica_mutsumi` speaker 可把文字合成为普通话源音频。直接输出不作为最终睦音色；将它接到 RVC v2 后，太阳宣言 `index 0.15 / pitch 0` 版本获得了用户的好评。权重保存在远程归档目录 `models/archive/qwen3-tts-bang-dream/`，可用于这条组合流程。
- **GPT-SoVITS v2 Pro Plus**：旧试听使用通用底模加 Qwen 或 RVC 参考音频；另有从 28 秒视频语音做出的短数据微调试听。后者样本极少，只是语气试验，不是可泛化的睦专属模型。对照音频和权重位置见[快速开始](快速开始.md#视频风格-few-shot-与短数据微调)与[环境记录](环境与模型记录.md#视频中的急促哭腔语气5-秒参考与短数据微调)。
- 详细环境与历史测试结果见[环境与模型记录](环境与模型记录.md)。

### 抽泣若叶睦基线 v1

这是当前确定的**抽泣语气基线**，用于保留若叶睦音色和这段哭腔参考带来的音质。它不是通用朗读基线：参考音频和微调语料都带有明显情绪，因此整段容易持续带哭腔。

| 项目 | v1 配置 |
| --- | --- |
| 合成框架 | GPT-SoVITS v2 Pro Plus 零样本合成（GSV） |
| GPT 微调权重 | `models/gpt-sovits/finetuned/video_style_28sec/GPT/MutsumiVideo28sec-e15.ckpt` |
| SoVITS 微调权重 | `models/gpt-sovits/finetuned/video_style_28sec/SoVITS/MutsumiVideo28sec_e8_s768.pth` |
| 参考音频 | [5 秒哭腔参考](../training_data/video_style_28sec/BV1XJpB6pEvu_5sec_cry_reference.wav) |
| 参考文本 | 本地私有转写文件 `training_data/video_style_28sec/5sec_cry_reference_prompt.txt` |
| 采样参数 | `top_k=15`、`top_p=0.6`、`temperature=0.6`、`speed=1.0` |
| 输出响度 | RMS 目标 `-27 dBFS`；CPU 推理，WAV 32 kHz / 16-bit |
| 当前试听样本 | [睡不醒测试文本 GSV](../outputs/基线/抽泣若叶睦基线_v1_GSV_睡不醒.wav)；同条件通用底模对照见[这里](../outputs/archieve/20261116_cleanup/试听试验/睡不醒_GSV_通用_5秒哭腔参考.wav) |

这条输出听起来持续带有抽泣和感叹语气，可能是三个条件叠加：目标稿包含密集拟声词，5 秒参考本身带哭腔，微调素材也只有约 28 秒且主要是急促情绪表达。GSV 会同时受目标文本、参考音频和微调权重影响，因而把表演风格延伸到较长片段。现有对照不足以精确分离三者各自的贡献；这不是单纯调高或调低音高能解决的问题。

若要减少连续哭腔，下一轮保持 v1 权重和目标文案不变，只换成同一说话人的平静参考；这样可直接判断参考语气影响。若拟声段仍过密，再固定参考，只精简或分段目标文案。每次只改一个条件，并另存为新版本；v1 保留作音色和音质锚点。

## 推荐操作流程

### 1. 准备输入音频

优先选择清楚、没有伴奏和背景音乐的独立人声。当前尝试表明，带 BGM 的唱歌素材转出来效果很差；需要这类素材时，先取得干声或分离人声，再做 RVC。下载的视频和独立音轨按 BV 号放在 `视频音频下载/<BV号>/`，个人录音也保存在 `视频音频下载/`，不要把生成结果混放进素材目录。

处理低男音时，先选一段有代表性的朗读，再对 pitch 做小范围阶梯比较。多腔调朗读可以用于试听，但粗哑感可能来自输入音域与目标音色不匹配；这次提高 pitch 后听感有明显改善。保留原始音频，确保后续可以用同一输入复跑。

### 2. 下载 B 站视频和原始音轨

本地使用 `yt-dlp`。这次给出的带 `/zh-Hans/` 前缀的链接被识别成普通网页；去掉语言前缀、使用标准 `https://www.bilibili.com/video/BV...` 地址后，B 站提取器能正常读取视频流。

```bash
# 视频：选可用的最佳 MP4 视频流和 M4A 音轨，合并为 MP4
yt-dlp --no-update --no-overwrites \
  -f 'bestvideo[ext=mp4]+bestaudio[ext=m4a]/best[ext=mp4]/best' \
  --merge-output-format mp4 \
  -o '视频音频下载/%(id)s/%(title)s.%(ext)s' \
  'https://www.bilibili.com/video/BVxxxxxxxxxxx'

# 单独保存未重编码的原始音轨，便于做音色转换或参考
yt-dlp --no-update --no-overwrites \
  -f 'bestaudio[ext=m4a]/bestaudio' \
  -o '视频音频下载/%(id)s/原始音轨.%(ext)s' \
  'https://www.bilibili.com/video/BVxxxxxxxxxxx'
```

某些视频的 4K 或 1080P 60 帧会受账号权限限制；本次三条下载得到的 1080p 视频和 M4A 音轨均可正常解码。需要训练或转换人声时，优先使用独立音轨，不要直接把带 BGM 的混合音频当作干声。

### 3. 上传输入并运行 RVC

以下示例固定其余参数，只把 pitch 设为 `+16`。比较其他 pitch 时，只改 `--pitch` 和输出文件名，以免同时改变多个因素。

```bash
# 本地工作区执行
ssh a100-whn 'mkdir -p /tmp/voca-rvc'
scp '视频音频下载/离骚-whn.m4a' a100-whn:/tmp/voca-rvc/source.m4a

# 远程主机执行
ssh a100-whn 'cd /data3/whn/Project-voca/frameworks/RVC && \
  export PYTHONPATH=/data3/whn/Project-voca/frameworks/RVC:/data3/whn/Project-voca/.venv-qwen/lib/python3.10/site-packages:/data3/whn/Project-voca/.venv-rvc-cpu/lib/python3.10/site-packages && \
  export rmvpe_root=/data3/whn/Project-voca/assets/rvc && \
  export CUDA_VISIBLE_DEVICES= OMP_NUM_THREADS=32 MKL_NUM_THREADS=32 OPENBLAS_NUM_THREADS=1 RVC_AUDIO_FORCE_CPU=1 && \
  /data3/whn/Project-voca/.venv-rvc-cpu/bin/python infer/cli.py \
    --model /data3/whn/Project-voca/models/rvc/mutsumi-rvc/mutsumi.pth \
    --input /tmp/voca-rvc/source.m4a \
    --output /tmp/voca-rvc/离骚_RVC_若叶睦_P16_i030.wav \
    --index /data3/whn/Project-voca/models/rvc/mutsumi-rvc/added_IVF345_Flat_nprobe_1_mutsumi_v2.index \
    --index-rate 0.30 --rms-mix-rate 0.45 --protect 0.50 \
    --pitch 16 --f0-method rmvpe --overwrite'

# 将成品取回本地试听目录
scp 'a100-whn:/tmp/voca-rvc/离骚_RVC_若叶睦_P16_i030.wav' \
  'outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P16_i030.wav'
```

实际远程推理使用 `.venv-rvc-cpu/bin/python`，并把 Qwen 环境的 site-packages 加入 `PYTHONPATH`。直接使用远程默认 `python` 曾触发 PyTorch 扩展加载错误；使用 Qwen Python 又缺少 RVC 环境依赖。请使用上面的解释器和路径组合。

### 4. 试听、验收和归档

每轮只变更一个主要参数。pitch 对照时固定 index、响度混合、protect 和 RMVPE；文件名写清 pitch 与 index。新结果暂存 `outputs/试听试验/`；确认长期使用的命名样本放进 `outputs/基线/`，其他对照按批次移入 `outputs/archieve/<批次>/试听试验/`。原始视频、原始音轨和录音留在素材目录。

可用 FFmpeg 检查编码、时长并完整解码：

```bash
ffprobe -v error \
  -show_entries stream=codec_name,sample_rate,channels \
  -show_entries format=duration \
  -of default=noprint_wrappers=1 'outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P16_i030.wav'

ffmpeg -v error -i 'outputs/archieve/20261116_cleanup/试听试验/离骚_RVC_若叶睦_P16_i030.wav' -f null -
```

本次《离骚》成品为 40 kHz、单声道 WAV，约 39.16 秒。远程临时文件确认已取回后，可清理 `/tmp/voca-rvc/`；这轮 pitch 对照现已归档在 `outputs/archieve/20261116_cleanup/试听试验/`。

## 已验证的经验

1. **输入音质决定上限。** 有 BGM 的唱歌音频转换效果很差。先找纯人声，或先做可靠的人声分离；当前没有把带伴奏音频转成睦音色作为合格流程。
2. **pitch 要根据输入音域试。** 原始低男音用默认音高时偏沙哑；`+10` 已有改善，`+16` 最接近用户预期，`+14` 到 `+18` 都适合对照。这个结果针对《离骚》输入，不代表其他录音也应该加同样半音数。
3. **用小范围阶梯对照。** 固定其他参数，生成相邻 pitch 版本并排听；不同时改 pitch、index 和 protect，否则难以判断哪项带来变化。
4. **index 是需要试听的音色匹配旋钮。** 当前普通朗读主配置用 `0.30`。历史汉堡独白用 `0.15` 和 `0` 做过对照；低 index 可能让音色贴合减弱，但可作为出现粗糙感时的排查方向，需在同一输入上验证。
5. **保持响度和保护参数稳定。** 当前《离骚》对照统一用 `rms-mix-rate=0.45`、`protect=0.50`、RMVPE；此前低响度对照用过 `protect=0.45`。CLI 中 `protect` 可设上限为 `0.50`。
6. **保留来源和生成物的边界。** 源音频按 BV 号或录音名称存放在 `视频音频下载/`；RVC/GSV 输出放在 `outputs/`；训练切片、标签和元数据放在 `training_data/`。归档时保留相对目录，避免历史链接失效。
7. **5 秒参考要配准确的参考文本。** 用视频结尾哭腔和开场急促语气分别作参考，再用同一条测试句比较通用底模与微调权重；这样能看参考片段带来的变化。参考文本有听感补词时要标出来，不能当成字幕原文。
8. **短片不通过循环凑训练时长。** 这条视频全长 28.14 秒，实际切出 6 段、约 27.5 秒可用语音。记录为 28 秒短数据微调，保留缺少的时长事实；训练集指标高不等于泛化好。
9. **微调和参考音频作用不同。** 5 秒参考只在合成时提供说话方式和音色线索；微调会同时学习说话人音色、习惯和表演风格，样本太少时无法把这些因素分开。急促、吸气、急喘、哭腔和撒娇目前没有已验证的独立参数。
10. **分开听 GSV 原声与 RVC 转换版。** 本轮先用 GSV 生成，再套睦 RVC 基线（`index=0.30`、`pitch=-1`、`protect=0.50`）。比较时保留两种版本，避免把语气变化误判成 RVC 音色变化；输出时长也受采样影响，不代表质量。
11. **记录实际试听结论，不预判赢家。** 学妹饭卡长台词的 GSV 原声现为“激动若叶睦基线”：用户认为音色正确、音高正常、整体质量很好，略微不干净。RVC 转换和响度匹配版本只作对照，不是基线。先前短句上 RVC 曾被反馈“好像好一点”但变响；这不替代用户对长台词 GSV 原声的选择。低温度版和 e10/e6 检查点版仍待试听。
12. **先排除过载，再处理合成粗糙感。** 用户选中的 GSV 哭腔原声峰值为 -9.54 dBFS、RMS -27 dBFS，文件没有数字削波；主观“炸麦”不等于波形削顶。RVC 版本响度高约 5 dB，先做响度匹配再比较，避免音量大造成更刺耳的错觉。
13. **尝试采样和检查点时一次只改一项。** 已从最终微调权重试 `temperature=0.4`，并以 GPT e10 / SoVITS e6 做较早检查点对照，保持参考音频、文本和 RMS 目标相同；需要用户试听后才能判断是否改善。输出 WAV 继续用 32 kHz / 16-bit；提高采样位数或重采样不能补回模型没生成的细节。
14. **用 F0 中位数估 pitch 起点，不把它当最终答案。** `pitch` 是半音移调。可先按 `12 × log2(目标参考 F0 中位数 / 输入 F0 中位数)` 算整数候选，再试听候选左右约 2 个半音。项目里《离骚》低声源中位数约 133 Hz，当前“无口”汉堡参考约 265 Hz，粗算约 +12；此前 +16 是《离骚》那条表演语气下的试听选择。汉堡参考来自 Qwen→RVC，F0 基本继承自 Qwen，不能当成真实原作若叶睦的独立频率测量。
