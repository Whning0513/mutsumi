# 快速开始

这里保留当前推荐操作。完整命令、音色配方和下一步功能见[可复用工作流](可复用工作流与下一步.md)；四条命名基线的输入、权重、参数和复刻步骤见[基线复刻指南](若叶睦基线复刻指南.md)。

## 安装本地入口

需要 Python 3.9 或更新版本。在 `Project-voca` 根目录执行：

```bash
sh scripts/bootstrap_local.sh
```

脚本会安装本地 CLI、创建被 Git 忽略的 `config/local.toml`（尚不存在时），并检查本地命令。FFmpeg/ffprobe 需另行安装。

编辑 `config/local.toml` 的远程主机和目录，然后检查本地工具、远程连接和模型环境：

```bash
voca doctor
voca doctor --remote
voca doctor --remote --profile mutsumi_excited_gsv
voca profiles
voca env snapshot
```

`config/local.toml` 不进入 Git。项目根目录已有示例配置 `configs/project.example.toml`，音色配方在 `configs/voice_profiles.toml`。
带 `--profile` 的预检会在远程 CPU 主机检查该配方所需的模型权重、参考音频、框架和推理脚本。

## 合成语音

将台词存为 `inputs/台本/` 下的本地 UTF-8 文本文件。它会被暂存到远程 CPU 主机完成推理，随后取回 WAV 并写出参数 manifest：

```bash
voca synth --profile mutsumi_daily_rvc \
  --text-file inputs/台本/我的朗读稿.txt \
  --output outputs/试听试验/日常试听.wav

voca synth --profile mutsumi_excited_gsv \
  --text-file inputs/台本/我的朗读稿.txt \
  --output outputs/试听试验/激动试听.wav
```

运行 `voca profiles <名称>` 查看配方。RVC 常调参数有 `--index-rate`、`--pitch`、`--protect`、`--rms-mix-rate`；GSV 常调参数有 `--top-k`、`--top-p`、`--temperature`、`--speed`、`--target-rms-dbfs`。命名基线本身不受临时参数覆盖影响。

统一 CLI 生成的成品语音默认在线性幅度上乘以 `3`，约为 `+9.54 dB`；峰值限制在 `-1 dBFS`，减少削波。可在本地配置的 `[audio]` 中调整 CLI 全局默认值，也可单次传 `--output-gain 1.0` 等覆盖。独立生成脚本也默认×3，并支持同名参数覆盖。RVC 前的 Qwen 源音频作为中间素材，不提前放大；最终转换结果会应用默认增益。

文案准备工具会离线清理 emoji 和标点，并可将长文按段落/句子切块：

```bash
python3 scripts/prepare_tts_text.py inputs/原始文本/原文.txt \
  --mode clean --split-mode auto --max-chars 220 \
  --output inputs/台本/朗读稿.txt --chunks-dir outputs/朗读稿_chunks
```

## 小剧场与视频

编辑 `inputs/小剧场/示例小剧场.json` 中每句的 `profile`、`text` 和 `pause_after_ms`。先验证，再生成拼接旁白：

```bash
voca scene validate inputs/小剧场/示例小剧场.json
voca scene render inputs/小剧场/示例小剧场.json --keep-lines
```

同一套 GSV 模型/参考音频的台词会批量合成，共享一次模型加载。每行可用 `parameters` 覆盖该路由的少数参数，例如 GSV 的 `temperature`、`speed`，或 RVC 的 `pitch`、`protect`、`index_rate`。`--keep-lines` 会在 `<成品名>_分轨/` 留下标准化逐句 WAV、`lines.json` 和逐句稿，方便剪辑与重排。

若同时传入动态背景，场景会输出带中文字幕的 MP4：

```bash
voca scene render inputs/小剧场/示例小剧场.json \
  --background-video path/to/background.mp4
```

现有旁白也可直接封装：使用 `voca video --background-video ...`，静态底图则使用 `--image ...`。两种方式都需要提供与音频逐字一致的 `--transcript-file`；字幕文字按人工稿强制对齐，不做 ASR 改写。字幕对齐在远端 CPU 完成，需要有效 SSH 配置；视频渲染需要本机 FFmpeg/ffprobe、Pillow 和可用的中文字体。可用 `--subtitle-style` 选择五种字幕样式：`outline`、`dark-rectangle`、`rounded-box`、`yellow-highlight`、`shadow`；深灰矩形和圆角底框可用 `--box-opacity` 调整透明度。完整示例见[字幕自动对齐与嵌入](字幕自动对齐.md#五种字幕样式)。

## 检查、对比、归档

```bash
voca qc outputs/试听试验/日常试听.wav
voca compare outputs/基线/选定基线.wav outputs/试听试验/日常试听.wav
voca index-assets
voca archive outputs/试听试验/旧试听.wav
```

`qc` 查看媒体流参数与平均/峰值响度；`compare` 生成本地 HTML 播放页；`index-assets` 写出本地素材清单。`archive` 默认只显示目标路径，确认后加 `--apply` 才移动文件到归档目录。遇到同名输出时，合成和视频命令默认停止；只有明确要替换时才传 `--overwrite`。

## 工作区数据边界

选定音频、试听成品、用户朗读稿、模型、参考音频、训练数据和背景素材只留在本地/远程工作区；`.gitignore` 排除生成音视频、模型权重、个人文本和本地配置。GitHub 仓库保存可复用的代码、配置模板和不含私人朗读稿的操作文档。
