# 中文字幕自动对齐与嵌入

`scripts/embed_chinese_subtitles.py` 把提供的文本当作 ground truth，不调用 ASR，也不做模糊匹配。它在 A100 主机上用 torchaudio 的 `MMS_FA` 多语种 CTC 强制对齐器，把原文逐字转成拼音并贴到音频时间轴上；然后生成 SRT，并烧录字幕。默认样式是白字黑描边。默认视频长边为 2048 像素，字幕字号 192、描边宽度 13 像素；每卡最多 18 个语音字符，每行偏好 9 个字符，以便大字号字幕保持在两行以内。短语停顿较小时会合并到同一字幕卡片，并在短语边界换成两行。对 1024×1024 静帧，输出是 2048×2048。当前默认用 CPU，避免占用 A100 上已满的显存。

## 首次配置

本机需要 Pillow、FFmpeg、SSH 和可用的 `a100-whn` SSH 别名。A100 主机需要含 `torch`、`torchaudio` 的 Python 环境，以及 `pypinyin`：

```sh
ssh a100-whn 'python3 -m pip install --target /data3/whn/Project-voca/.venv-qwen/lib/python3.10/site-packages pypinyin==0.55.0'
```

首次运行会从 PyTorch 官方模型托管下载约 1.3 GB 的 MMS_FA 权重，保存在 A100 的 `/data3/whn/Project-voca/.cache/mms-fa`；后续运行复用缓存。

## 运行

```sh
python3 -m pip install --user -r requirements/subtitles.txt
python3 scripts/embed_chinese_subtitles.py \
  --image videos/bd7a92e6f69faada8abebc035ef79a46.jpg \
  --audio 'outputs/基线/无口若叶睦基线_RVC_汉堡独白_低索引.wav' \
  --transcript-file 'inputs/台本/若叶睦_汉堡独白_字幕.txt' \
  --output 'videos/若叶睦_RVC_汉堡独白_低索引.mp4' \
  --normalize-audio
```

如果 SSH 主机别名、远端 Python 或模型缓存目录不同，可以传 `--aligner-host`、`--remote-python`、`--remote-cache`。`--threads` 控制远端 CPU 线程数。多音字、数字读法或英文缩写需要指定读音时，可传 JSON `--pinyin-map`，例如 `{"行":"xing","1":"yi"}`；键为原文中的单个字符，值为实际读出的拼音。其余 `--ffmpeg`、`--font`、`--max-chars`、`--font-size`、`--stroke-width` 参数用于本地视频生成与字幕样式。

## 五种字幕样式

通过 `--subtitle-style` 选择烧录到视频里的字幕外观；默认是 `outline`。`--box-opacity`（0–100，默认 84）只控制带底框的两种样式。字幕文字和 SRT 时间轴不随样式改变。

| 参数 | 外观 |
| --- | --- |
| `outline` | 白字黑描边，默认样式，适合复杂背景 |
| `dark-rectangle` | 白字置于深灰色直角矩形底框，留有内边距 |
| `rounded-box` | 白字置于半透明深色圆角底框 |
| `yellow-highlight` | 黄字黑描边，适合强调感较强的短视频 |
| `shadow` | 白字配柔和黑色投影，不加描边和底框 |

例如，已有旁白配静态图时使用深灰矩形底框：

```bash
voca video --image path/to/background.jpg \
  --audio path/to/narration.wav \
  --transcript-file path/to/transcript.txt \
  --output path/to/video.mp4 \
  --subtitle-style dark-rectangle --box-opacity 88
```

`voca scene render` 也支持相同的 `--subtitle-style` 和 `--box-opacity` 参数。底框透明度较高时能遮住复杂画面；若希望背景纹理透出更多，可降低 `--box-opacity`。

可用 `--long-edge` 改变输出长边（例如 `2048` 或 `2560`），`--chars-per-line` 调整短语换行偏好，`--max-cue-duration` 限制单张字幕卡片的最长时长。输入静帧低于目标尺寸时使用 Lanczos 插值放大，并默认轻微锐化亮度通道（`--sharpen 0.25`）；传 `--sharpen 0` 可关闭，取值范围为 0 到 1.5。插值和锐化会改善像素尺寸与边缘观感，但不能恢复源图没有记录的细节；若需要真实细节提升，优先使用更高分辨率的源图。

对齐完成后，脚本会检查每个语音字符是否都拿到单调、有效的时间区间；超长音节若跨过明显静音，会按音频能量裁掉静音尾部。脚本默认还会生成逐字时间和置信度报告 `<视频名>.alignment.json`，并列出低置信度字符。置信度只能发现明显的文本/读音不匹配，不能代替试听校验。多音字、英文缩写和数字若读音不确定，应先把稿子写成音频实际读出的文字/读法。成功时会生成与 MP4 同名的 `.srt`。`--normalize-audio` 可将音频响度标准化到 -16 LUFS；默认保留原始音量。
